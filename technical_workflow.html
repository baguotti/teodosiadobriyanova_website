LLM Technical Architecture & Deployment Specification

Use this reference document to plan, bootstrap, build, and deploy new websites using the user's standardized tech stack and workflow.

1. Tech Stack Specification

Layer Library / Tool Configuration Notes
Framework React 19 (react, react-dom) Strict Mode, TSX
Language TypeScript (~5.9+) tsconfig.json strict mode
Build Tool Vite 7+ (vite, @vitejs/plugin-react) Configured in vite.config.ts
Styling Tailwind CSS v4 (@tailwindcss/vite) Configured via Vite plugin
Icons & Motion lucide-react, gsap, @gsap/react GSAP context hook pattern
Routing React Router v7 (react-router-dom) SPA Client Routing

4. Deployment & Domain Transfer Specification

Hosting Pipeline

  • Platform: Vercel (connected to GitHub main branch).
  • Framework Preset: Vite
  • Build Command: npm run build (tsc -b && vite build)
  • Output Directory: dist
  • Install Command: npm install

Custom Domain & DNS Mapping

  1. CNAME File: Placed at repository root containing the custom domain (e.g. customdomain.com).
  2. DNS Records:
    • Apex (@): Record A pointing to Vercel IP 76.76.21.21
    • Subdomain (www): Record CNAME pointing to cname.vercel-dns.com
  3. SSL: Managed automatically via Vercel Edge.
